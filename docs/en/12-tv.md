# TV app (Android TV)

A read-only screen: joins a game as `screen` and never sends commands besides `hello`,
`pong` and `leave`. Project rules live in `tv/CLAUDE.md`.

## Connecting

1. **Server.** On start the app returns to the last server. Otherwise it searches the network
   (UDP broadcast to 255.255.255.255 and each /24 broadcast, three probes over 2.5 s); if
   exactly one server is found and none is saved, it connects automatically. An address
   can be typed with the remote.
2. **Game.** The app lists the live games (`GET /api/games`, refreshed every 5 s): title,
   pack, phase, players — never PINs. Choosing one *watches* it
   (`POST /api/games/{id}/watch`): the TV shows the game but gets no PIN or link.
   «Ввести PIN» opens a digit pad (the remote's number keys work too); the game is looked
   up after the 6th digit and joined as `screen` with the PIN.
3. **Display.** The `{pin, token}` is saved per server, so a restart goes straight back to
   the display. Close code `4004` (game closed) or `4001`/`4003` forgets the token and returns
   to the list with a notice; other drops reconnect with the same token.

**Back**, **Menu** or **OK** on the display opens a menu: «Продолжить показ», «Сменить игру»,
«Сменить сервер» (both changes send `leave`).

## What it shows

| Phase | Display |
|---|---|
| lobby | game title, pack title, joined players; when joined with the PIN also the PIN, the share link (`game.link`) and its QR code, otherwise «Ссылку для входа раздаёт администратор» |
| board | all categories (≤ 10) × values on one screen, played cells empty, «Выбирает: …» |
| question / answering | category and value, question blocks, timer bar, «Отвечает: …» |
| reveal | the answer and the host comment |
| round_end / finished | standings / podium |

Special questions get a 3-second full-screen reveal (a drawn cat, 🔨, 🛡, ×2) before
their media starts; the auction shows the high bid (red «ВА-БАНК» on an all-in), the leader,
whose turn it is and who passed. In the final the TV shows the themes being struck out,
which finalists have bet (never the amounts), a ring countdown while answers are typed,
each answer and ±bet as the host judges it, and finally the correct answer and ranking.

A scoreboard strip (gold ring = chooser, accent ring = answering, dimmed = already
answered wrong) is shown during the board and questions. Video and audio autoplay with
sound once per question; short generated tones mark buzzes, judgements and timeouts.
The screen stays awake. While offline it keeps the last picture and shows a banner.

## Layout

Everything is drawn on a fixed 1920×1080 stage scaled to the screen, so the sizes in
`DESIGN_MANIFEST.md` are literal. Category headers use 24 px for legibility at a
distance. SVG images are not supported on the TV (a placeholder is shown).

## Build

```bash
make -C tv analyze test
make -C tv build-apk-debug   # build/app/outputs/flutter-apk/app-debug.apk
make -C tv build-apk         # release APK, signed with the debug key
```

App id `dev.svoyigra.tv`, launcher banner, leanback launcher, landscape. Fonts are
bundled because a TV may be offline.
