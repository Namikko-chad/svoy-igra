# Введение

«Своя игра» — викторина в духе Jeopardy для компании в одной комнате (или в одной сети).
Игру ведёт сервер на Go; участники играют из веб-браузера или с Android-телефона,
а Android TV (или браузер на проекторе) показывает табло.

## Игры и роли

Один сервер ведёт много игр одновременно. Кто угодно может **создать игру** — пароль не нужен —
выбрав PIN админа; создатель становится админом игры и получает 6-значный PIN игры
и ссылку-приглашение (`…/g/<PIN>`), которую можно отправить в чат. Ссылка открывает веб-сайт или, на
Android, приложение. Для **входа** нужен PIN игры, затем выбирается роль:

| Роль | Входит с | Может |
|---|---|---|
| Игрок | PIN игры + имя | в свой ход выбрать вопрос; нажать «Дать ответ», когда кнопка откроется; по желанию ввести ответ текстом |
| Ведущий | PIN игры (один ведущий одновременно) | видеть правильный ответ, оценивать ответы, управлять игрой (старт, пропуск, раунды, завершение, сброс), настраивать таймеры |
| Админ | PIN игры + PIN админа | выбирать пак, управлять общей библиотекой паков и редактировать её (импорт/экспорт `.dub`, блокировка паков), скачивать/загружать файл игры; видеть очки игроков (и исправлять их), устройства, задержку, статистику реакции; сдвигать кнопку каждого игрока, включать компенсацию задержки, удалять игроков, переименовывать игру, менять PIN админа, закрывать игру |
| Экран | PIN игры — или, без него, игра, выбранная из публичного списка | показывать табло, вопросы с медиа, таймеры и очки; без управления. Экран, выбранный из списка, никогда не узнаёт PIN, поэтому не показывает QR-код для входа |

Список игр на сервере публичный, но PIN в нём никогда не показываются: играть, вести или администрировать
могут только те, кому передали ссылку или PIN. Игроки и ведущий могут загружать собственные аватары. Игра, к которой никто не подключён в течение
часа, удаляется. Паки общие для всех игр и
переживают их; **заблокированный** пак нельзя изменить или удалить — при редактировании создаётся копия.

## Как разыгрывается вопрос

1. Выбирающий (последний игрок, ответивший правильно) выбирает клетку — категорию и стоимость.
2. Вопрос появляется у всех. Идёт общий таймер (по умолчанию 10 с).
3. Когда он заканчивается, сервер открывает «Дать ответ» на устройстве каждого игрока — в
   один и тот же момент для всех, если админ не сдвинул чью-то кнопку.
4. Побеждает первое нажатие, дошедшее до сервера; этот игрок отвечает вслух (и может ввести ответ текстом).
5. Ведущий оценивает ответ. Верно: стоимость прибавляется, игрок становится выбирающим. Неверно:
   остальные игроки снова получают кнопку (по желанию стоимость вычитается).
6. Показывается правильный ответ; ведущий возвращается к табло.

Игра состоит из раундов; в каждом раунде до 10 категорий, каждая категория — столбец
вопросов возрастающей стоимости.

## Клиенты

| Клиент | Технология | Роли |
|---|---|---|
| Веб-сайт | Vue 3 + Vite, раздаётся бэкендом | создание/вход, игрок, ведущий, админ (+ редактор паков), экран |
| Приложение | Flutter, Android / Windows / Linux / macOS | те же, что у веб-сайта; открывает ссылки-приглашения |
| ТВ-приложение | Flutter, Android TV | только экран; выбирает игру из списка |

## Хранение данных

Сервера баз данных нет. Паки вопросов — это файлы SQLite, которые хранит бэкенд, а
передаются они как архивы `.dub` (ZIP из `pack.sqlite` + `media/`). Каждая игра (игроки,
очки, сыгранные вопросы, история, статистика) — это JSON-файл, который бэкенд постоянно
сохраняет; админ может скачать или загрузить его содержимое.
