# Дизайн-система

Переносимый визуальный язык — цвет, типографика, отступы, компоненты и правила — описан в
[`DESIGN_MANIFEST.md`](../../DESIGN_MANIFEST.md) в корне репозитория. Все три
клиента реализуют одни и те же токены; эта страница говорит, где именно.

| Клиент | Токены | Компоненты |
|---|---|---|
| Веб | `frontend/src/styles/tokens.css` (пользовательские свойства CSS), `base.css` | `frontend/src/components/` (`GameBoard`, `BuzzerButton`, `TimerBar`, `Scoreboard`, …) |
| Приложения (Android, десктоп) | `clients/lib/core/theme.dart` (`AppColors`, `AppText`, `buildTheme`) | `clients/lib/features/game/`, `clients/lib/features/player/buzzer.dart` |
| ТВ | `tv/lib/core/theme/` (`AppColors`, `AppText`, `AppTheme`) | `tv/lib/features/display/widgets/`, `tv/lib/core/widgets/tv_button.dart` |

## Заметки по клиентам

- **Шрифты.** Unbounded (заголовки), Inter (основной текст), JetBrains Mono (метрики). Веб-клиент
  загружает их из Google Fonts с системными запасными шрифтами; приложения и ТВ включают файлы в сборку.
- **Веб.** Без UI-фреймворка; компоненты — обычные Vue + CSS. Раскладки mobile-first
  (360 px) для игрока/ведущего/админа; `/screen` рассчитан на 1920×1080 и масштабируется.
- **ТВ.** Фиксированная сцена 1920×1080, масштабируемая под экран, поэтому размеры в пикселях из манифеста буквальны.
  Заголовки категорий — 24 px (больше диапазона манифеста) для чтения на расстоянии.
  У каждого элемента управления есть акцентное кольцо фокуса для работы с D-pad.
- **Цвета задержки** (админ): `< 60 ms` успех, `60–150 ms` предупреждение, `> 150 ms` опасность.

Добавление правила: переносимое → `DESIGN_MANIFEST.md`; специфичное для клиента (файл, библиотека) → эта
страница и `CLAUDE.md` этого клиента.
