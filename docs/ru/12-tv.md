# ТВ-приложение (Android TV)

Экран только для чтения: входит в игру как `screen` и никогда не отправляет команды, кроме `hello`,
`pong` и `leave`. Правила проекта находятся в `tv/CLAUDE.md`.

## Подключение

1. **Сервер.** При запуске приложение возвращается к последнему серверу. Иначе оно ищет серверы в сети
   (широковещательный UDP на 255.255.255.255 и на широковещательный адрес каждой /24, три запроса за 2,5 с); если
   найден ровно один сервер и сохранённого нет, оно подключается автоматически. Адрес
   можно ввести с пульта.
2. **Игра.** Приложение показывает список текущих игр (`GET /api/games`, обновляется каждые 5 с): название,
   пак, фаза, игроки — но никогда не PIN. Выбор игры включает *наблюдение* за ней
   (`POST /api/games/{id}/watch`): ТВ показывает игру, но не получает ни PIN, ни ссылку.
   «Ввести PIN» открывает цифровую клавиатуру (цифровые кнопки пульта тоже работают); игра ищется
   после ввода 6-й цифры, и приложение входит в неё как `screen` по PIN.
3. **Отображение.** `{pin, token}` сохраняется для каждого сервера, поэтому после перезапуска приложение сразу возвращается к
   отображению. Код закрытия `4004` (игра закрыта) или `4001`/`4003` забывает токен и возвращает
   к списку с уведомлением; при других обрывах приложение переподключается с тем же токеном.

**Back**, **Menu** или **OK** на экране отображения открывают меню: «Продолжить показ», «Сменить игру»,
«Сменить сервер» (обе смены отправляют `leave`).

## Что показывается

| Фаза | Отображение |
|---|---|
| lobby | название игры, название пака, присоединившиеся игроки; при входе по PIN также PIN, ссылка-приглашение (`game.link`) и её QR-код, иначе «Ссылку для входа раздаёт администратор» |
| board | все категории (≤ 10) × стоимости на одном экране, сыгранные клетки пустые, «Выбирает: …» |
| question / answering | категория и стоимость, блоки вопроса, полоса таймера, «Отвечает: …» |
| reveal | ответ и комментарий ведущего |
| round_end / finished | итоги / пьедестал |

Специальные вопросы получают 3-секундное полноэкранное объявление (нарисованный кот, 🔨, 🛡, ×2) перед
запуском их медиа; аукцион показывает старшую ставку (красное «ВА-БАНК» при ва-банке), лидера,
чей сейчас ход и кто спасовал. В финале ТВ показывает вычёркивание тем,
кто из финалистов сделал ставку (никогда не суммы), кольцевой обратный отсчёт, пока вводятся ответы,
каждый ответ и ±ставку по мере оценки ведущим и в конце — правильный ответ и итоговый рейтинг.

Полоса таблицы очков (золотое кольцо = выбирающий, акцентное кольцо = отвечающий, затемнён = уже
ответил неверно) показывается во время табло и вопросов. Видео и аудио воспроизводятся автоматически со
звуком один раз за вопрос; короткие сгенерированные тоны отмечают нажатия, оценки и истечение времени.
Экран не гаснет. Без связи он сохраняет последнюю картинку и показывает баннер.

## Раскладка

Всё рисуется на фиксированной сцене 1920×1080, масштабируемой под экран, поэтому размеры в
`DESIGN_MANIFEST.md` буквальны. Заголовки категорий используют 24 px для читаемости на
расстоянии. Изображения SVG на ТВ не поддерживаются (показывается заглушка).

## Сборка

```bash
make -C tv analyze test
make -C tv build-apk-debug   # build/app/outputs/flutter-apk/app-debug.apk
make -C tv build-apk         # release APK, подписан debug-ключом
```

Id приложения `dev.svoyigra.tv`, баннер лаунчера, leanback-лаунчер, альбомная ориентация. Шрифты
включены в сборку, потому что ТВ может быть без интернета.
