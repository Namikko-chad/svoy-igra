[English](README.md) · **Русский**

**Своя игра** — бесплатная викторина в духе телеигры «Своя игра» (Jeopardy!) с открытым
исходным кодом для компании в одной комнате или в одной сети. Небольшой сервер на Go
ведёт игры; игроки жмут кнопку «Дать ответ» со **своих телефонов, ноутбуков или из
браузера**, ведущий оценивает ответы, а **телевизор, проектор или Android TV**
показывает табло. Без регистрации, без облака, без сервера баз данных — один Docker-образ
на ~13 МБ или один исполняемый файл.

Подходит для домашней вечеринки, корпоратива и тимбилдинга, урока или классного часа,
квиза в баре, клуба «Своей игры» или «Что? Где? Когда?».

## Возможности

- **Честная кнопка даже по Wi-Fi**: «Дать ответ» открывается на всех устройствах
  одновременно; сервер измеряет задержку каждого игрока и может её компенсировать.
  Админ видит время реакции и может сдвинуть кнопку любого игрока.
- **Много игр на одном сервере**: у каждой свой 6-значный PIN, ссылка `…/g/<PIN>` и
  QR-код для входа.
- **Четыре роли**: игрок, ведущий (видит ответ, оценивает, ведёт игру), админ (паки,
  очки, игроки, задержка) и экран (табло для ТВ или проектора).
- **Классические правила**: раунды × до 10 тем × стоимость 100, 200, 300…; спецвопросы —
  «Кот в мешке», «Аукцион», вопрос без риска, двойной вопрос; финал со ставками.
- **Встроенный редактор паков вопросов** с markdown, картинками, аудио и видео; паки —
  переносимые файлы `.dub` (ZIP из SQLite и медиа): импорт, экспорт и
  [генерация скриптом или нейросетью](docs/ru/13-pack-format.md).
- **Клиенты для всех устройств**: веб-сайт (Vue 3), приложение для **Android, Windows,
  Linux и macOS** (Flutter), приложение-экран для **Android TV**. Сервер находится в
  локальной сети автоматически.
- **Свой сервер, работает без интернета**: ноутбук, мини-ПК, Docker или даже контейнер на
  **роутере MikroTik**. Игры и паки — обычные файлы.

## Быстрый старт

### Docker (рекомендуется)

```bash
git clone https://github.com/Namikko-chad/svoy-igra.git
cd svoy-igra
docker compose up -d --build
```

Откройте `http://<ваш-ip>:3050`, нажмите «Создать игру» и отправьте игрокам ссылку или QR-код.

### Из исходников

```bash
cp backend/.env.example backend/.env
make backend                              # сервер на :3050 (+ UDP 3051 для поиска в сети)
make frontend                             # веб-клиент на :3000 — откройте http://<ваш-ip>:3000
```

### Приложения

Готовые сборки — Windows `.zip`, macOS `.zip`, Linux `.tar.gz`, APK для телефона и APK для
Android TV — на странице [Releases](https://github.com/Namikko-chad/svoy-igra/releases/latest).
Собрать самому: `make -C clients build-apk`, `make -C tv build-apk`,
`make -C clients build-linux` / `build-windows` / `build-macos`.
Подробно: [Начало работы](docs/ru/03-getting-started.md).

## Как разыгрывается вопрос

1. Выбирающий игрок выбирает тему и стоимость на табло.
2. Вопрос появляется на всех экранах; идёт общий таймер чтения (по умолчанию 10 с).
3. Кнопка «Дать ответ» открывается у всех игроков одновременно; побеждает первое нажатие.
4. Игрок отвечает вслух (или вводит текст); ведущий засчитывает или нет.
5. Верно — очки начисляются, игрок выбирает следующий вопрос. Неверно — жать могут остальные.

Все правила: [Правила игры и паки](docs/ru/07-game-and-packs.md).

## Устройство репозитория

| Папка | Что |
|---|---|
| [`backend/`](backend/) | Сервер на Go — движок игры, REST + WebSocket, библиотека паков, поиск в LAN |
| [`frontend/`](frontend/) | Веб-клиент на Vue 3 — игрок, ведущий, редактор паков, админ, экран |
| [`clients/`](clients/) | Приложение на Flutter для Android, Windows, Linux и macOS — те же возможности, что у сайта |
| [`tv/`](tv/) | Приложение на Flutter для Android TV — только экран |
| [`docs/`](docs/) | Документация ([ru](docs/ru/02-table-of-contents.md), [en](docs/en/02-table-of-contents.md)) |

Без сервера БД: паки вопросов — файлы `.dub` (ZIP из `pack.sqlite` + `media/`), каждая
игра — JSON-файл; админ может их скачать и загрузить. [Протокол](docs/ru/05-protocol.md)
(REST, WebSocket, формат паков) описан — можно написать свой клиент.

## Вопросы и ответы

**Это бесплатно?** Да, лицензия MIT, без рекламы, регистрации и телеметрии.

**Нужен ли интернет?** Нет. Всё работает в одной локальной сети — серверу, телефонам и
телевизору достаточно видеть друг друга.

**Сколько игроков?** Сколько поместится в комнате — у каждого своё устройство.

**Где взять вопросы?** Написать во встроенном редакторе, импортировать пак `.dub` или
сгенерировать его из таблицы или с помощью ИИ-ассистента по
[описанию формата паков](docs/ru/13-pack-format.md).

**Это SIGame?** Нет. Это независимый проект со своим сервером, клиентами и форматом паков `.dub`.
